# FireSafe Atlas

An open-source climate justice GIS toolkit for mapping wildfire vulnerability and creating preparedness resources for underserved rural communities.

## Project Team

**Conception / Design Lead:** Rhea Ghosal  
**Reviewer:** Catherine Mudd  
**Intern / Research & GIS Support:** Neil Panchal  

## Project Purpose

FireSafe Atlas uses free public GIS data to identify wildfire-vulnerable rural communities and turn the analysis into practical preparedness tools for families, schools, NGOs, and local leaders.
