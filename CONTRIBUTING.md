# Contributing To FireSafe Atlas

## Contribution Rules

1. Do not commit passwords, tokens, API keys, or private student information.
2. Every data source must be documented in `methodology/data-sources.md`.
3. Every map layer must include its source, date accessed, and limitation.
4. Do not claim that FireSafe Atlas predicts fires unless a true predictive model is built and validated.
5. Do not claim that smoke caused attendance changes. Use cautious language such as "may indicate a need for precautions."
6. Keep the dashboard static for version 1. Use GitHub Pages unless a written VM justification is approved.
7. Use pull requests for major edits after the first working dashboard is published.
